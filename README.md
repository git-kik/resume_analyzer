# smartRecurit- Resume Screener 
Automate the resume screening process using ML and NLP to parse key resume contents such as education, experience, and skills & compare with  job descriptions text in a user friendly manner. 
Learn more: [Detail-Project-Document](./upload_resume/8th-project.pdf)

----
## Tech Stacks
- **Python** – Scripting 
- **Flask** – Backend development
- **Scikit-learn** - Training SVC model
- **SQlite** - Database
- **Microsoft-Learn api** – Course recommendations
- **OpenAI api** - LLM integrations

## Setup Instruction

### Pre-requisite
```bash
> python3 -V
  python 3.10.0
```
### Clone the Repo
```bash
git clone https://github.com/yourusername/resume_analyzer.git
cd resume_analyzer
```

### Setup you virtual environment & install requirements.txt

```bash
pip install -r requirements.txt
```

### Run flask app at : `localhost:5000`
 ```bash
python3 main.py
```
